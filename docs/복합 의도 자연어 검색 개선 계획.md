# 복합 의도 자연어 검색 개선 계획

## 배경

현재 프로토타입은 자연어 질의와 논문 `Title + Abstract + D/T/M`의 임베딩 cosine similarity로 전체 논문을 1차 검색한다. 단순 주제 질의에는 유효하지만, 여러 조건을 동시에 요구하는 연구 탐색 질의에서는 일부 조건만 유사한 논문도 상위에 올 수 있다.

예를 들어 다음 질의는 단일 주제가 아니라 여러 필수 조건의 교집합이다.

> 최근 표현 학습 연구에서 모델의 귀납적 편향이 일반화 성능에 어떤 영향을 미치는지 분석한 논문 중, 이론적 분석과 실험적 검증을 함께 제시한 연구를 추천해줄 수 있어?

핵심 조건은 `표현 학습`, `귀납적 편향`, `일반화`, `이론 분석`, `실험 검증`이다. 현재의 단일 유사도 점수는 이론 또는 실험 중 하나만 만족하는 논문을 충분히 낮추지 못한다.

## 목표

자연어를 주 입력으로 유지하면서, 복합 질의의 필수 조건을 만족하는 논문을 상위에 배치한다. Domain / Task / Method(D/T/M)는 검색 벡터를 대체하지 않고, 의도 해석·필터링·설명에 쓰는 보조 정보로 유지한다.

## 단계별 설계

### 1. 질의 분해

질의를 아래 구조로 분해한다.

```json
{
  "topic": ["representation learning", "inductive bias"],
  "question": ["effect on generalization"],
  "required_evidence": ["theoretical analysis", "experimental validation"],
  "method_or_setting": [],
  "must_have": ["theoretical analysis", "experimental validation"]
}
```

- LLM structured output 또는 보수적인 규칙 기반 추출을 사용한다.
- `must_have`는 단순 가점이 아니라 재정렬 단계의 필수 조건으로 취급한다.
- 질의 원문도 그대로 보존해 semantic retrieval 입력으로 사용한다.

### 2. 하이브리드 후보 검색

후보군은 서로 다른 강점을 갖는 두 검색기의 합집합으로 만든다.

1. Dense retrieval: 기존 text embedding cosine Top-N
2. Sparse retrieval: BM25의 제목·초록 Top-N

Dense retrieval은 의미가 비슷한 표현에, BM25는 `oversmoothing`, `inductive bias`, `scaling law`, `CAP theorem` 같은 정확한 전문 용어에 강하다. 두 결과는 reciprocal-rank fusion(RRF) 또는 정규화 점수 합으로 결합한다.

초기 권장값은 각 검색기 Top-100, 병합 후 Top-100이다.

### 3. 제약형 2차 재정렬

병합된 상위 후보만 cross-encoder 또는 LLM judge로 재평가한다. 평가기는 제목·초록·구조화된 질의 조건을 보고 다음을 각각 판정한다.

```text
1. 핵심 주제를 직접 다루는가?
2. 질의가 요구한 이론 분석을 제공하는가?
3. 질의가 요구한 실험·정량 검증을 제공하는가?
4. 질문의 방법·시스템·응용 조건과 맞는가?
```

- 필수 조건이 누락되면 강한 패널티 또는 제외를 적용한다.
- 후보마다 `topic_score`, `evidence_score`, `constraint_score`, `final_score`를 저장해 추천 이유를 설명 가능하게 한다.
- LLM judge는 1차 검색 전체가 아니라 Top-50~100에만 사용해 비용을 통제한다.

### 4. 메타데이터 확장

기존 D/T/M만으로는 연구의 증거 형태와 기여를 충분히 표현할 수 없다. 아래 필드를 D/T/M과 별도로 추출·저장한다.

| 필드 | 예시 | 활용 |
| --- | --- | --- |
| `contribution_type` | theoretical analysis, algorithm, system, benchmark, survey | 기여 유형 필터 |
| `evidence_type` | proof, experiment, ablation, simulation, deployment | 이론·실험 조건 판정 |
| `setting` | language model, distributed database, molecular graph | 적용 환경 필터 |
| `claims` | improves transfer, mitigates oversmoothing | 결과 설명·재정렬 |

이 메타데이터는 자연어 embedding 점수를 대체하지 않으며, 필수 조건 필터·설명·분석을 보완한다.

### 5. 코퍼스 커버리지 관리

검색 실패는 모델 문제가 아니라 코퍼스에 논문이 없어서 발생할 수 있다. 특히 최신 LLM scaling-law 연구처럼 기존 OGBN-Arxiv 표본의 시점 이후에 나온 분야는 별도 수집·임베딩이 필요하다.

- 질의별로 최신성 요구를 감지한다.
- 최신성이 필요한 경우 OpenAlex, arXiv 등에서 수집한 별도 코퍼스를 병합한다.
- 결과에 데이터 기준일과 코퍼스 출처를 표시한다.

## 평가 계획

현재 600개 synthetic 질의는 파이프라인 및 모델 간 초기 비교용으로 사용한다. 최종 품질 판단에는 아래 평가를 추가한다.

1. 사람이 작성한 복합 질의 50~100개
2. 한국어·영어 질의를 모두 포함한 교차 언어 표본
3. 전체 코퍼스 Top-10 결과에 대한 수동 relevance 판정
4. Text-only, Dense+BM25, 제약형 재정렬을 동일 질의에서 비교
5. Recall@K, graded NDCG@K 외에 필수 조건 충족률을 보고

## 구현 우선순위

1. BM25 인덱스와 dense/BM25 후보 결합
2. 질의 분해 JSON schema와 `must_have` 조건 추출
3. Top-50 제약형 재정렬 및 결과 설명
4. `contribution_type`, `evidence_type`, `setting` 메타데이터 생성
5. 최신 논문 코퍼스 추가 및 실제 사용자 질의 평가

## 현재 원칙

- 기본 검색은 검증된 text-only dense retrieval을 유지한다.
- D/T/M과 인용 그래프는 충분한 평가 근거 없이 점수에 강제 결합하지 않는다.
- 인용 그래프는 결과 다양화, 관련 논문 확장, 설명에 우선 사용한다.
- synthetic 평가 수치는 유망성 신호이며, 실제 사용자 질의 일반화 성능의 최종 근거는 아니다.
