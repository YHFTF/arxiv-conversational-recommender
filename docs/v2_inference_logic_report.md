# 자연어 추천 추론 엔진(v2) 작동 로직 및 프로세스 명세서

본 문서는 Arxiv 지식 그래프 기반 논문 추천 시스템의 자연어 인터페이스 모델인 `run_nl_inference_v2.py`의 아키텍처 구성, 작동 매커니즘 및 상세 프로세스를 보고서 형식으로 기술합니다.

---

## 1. 개요

`run_nl_inference_v2.py`는 사용자의 자연어 질의를 분석하여 그래프 신경망 및 지식 임베딩 공간에서 최적의 논문을 검색 및 추천하는 End-to-End 추론 엔진입니다. 

본 엔진은 거대 언어 모델의 텍스트 표상 능력과 LightGCN 기반 그래프 임베딩의 협업 필터링 능력을 결합한 하이브리드 추천 방식을 채택하고 있습니다. 사용자의 추상적인 검색 의도를 구체적인 학술적 속성과 정렬함으로써, 인용 관계가 없는 콜드 스타트 상황에서도 일관성 있는 추천 품질을 보장하도록 설계되었습니다.

---

## 2. 핵심 아키텍처 및 기술 스택

본 엔진은 다음과 같은 핵심 모듈과 알고리즘으로 구성되어 있습니다.

### 2.1. 텍스트 의미 벡터 추출
사용자 질의의 거시적 의미 구조를 보존하기 위해 OpenAI의 3세대 소형 임베딩 모델인 `text-embedding-3-small`을 활용합니다. 이를 통해 원본 자연어 질의 전체를 128차원의 고정밀 실수 벡터로 실시간 인코딩합니다.

### 2.2. 학술 속성 파싱
질의 텍스트에 포함된 미시적 학술 요구사항을 규명하기 위해 `gpt-4o-mini` 모델을 사용하여 개체명 인식 및 속성 분류를 수행합니다. 질의문으로부터 **Domain**, **Task**, **Method**를 사전 정의된 JSON 스키마로 추출합니다.

### 2.3. 어휘 검색 매핑
파싱된 자연어 학술 용어를 학습 데이터셋 내부의 고유 노드 ID로 매핑하기 위해 휴리스틱 규칙 기반의 문자열 일치 알고리즘을 사용합니다. 완전 일치, 부분 일치, 단어 토큰 단위 포함 여부를 순차적으로 탐색하여 지식 그래프 상의 엔티티 ID를 복원합니다.

### 2.4. 지식 합성 그래프 신경망
복원된 엔티티 ID를 활용해 모델이 학습한 고유의 지식 가중치(`domain_emb`, `task_emb`, `method_emb`)를 쿼리에 수혈하며, 학습된 LightGCN 전파 모델을 기반으로 16,000편의 논문 노드 최종 표상을 도출합니다.

## 3. 상세 처리 프로세스

엔진이 구동되어 자연어 질의로부터 최종 추천 결과를 도출하는 과정은 총 5단계의 파이프라인으로 세분화됩니다.

```
[자연어 질의 입력]
       │
       ├──> [단계 1] OpenAI 128차원 의미 벡터 실시간 추출
       │
       ├──> [단계 2] gpt-4o-mini 기반 학술 속성 추출
       │
       ├──> [단계 3] Fuzzy Matching 알고리즘을 통한 데이터셋 고유 ID 변환
       │
       ├──> [단계 4] 가상 쿼리 임베딩의 동적 조합
       │
       └──> [단계 5] GNN 종단 임베딩 생성 및 코사인 유사도 기반 Top-K 추천
```

### [단계 1] 질의 텍스트의 128차원 인코딩
사용자가 입력한 자연어 질의 $Q$를 `text-embedding-3-small` API로 전송하여 차원 압축된 128차원 텍스트 벡터 $\vec{e}_{\text{text}}$를 획득합니다.
$$\vec{e}_{\text{text}} \in \mathbb{R}^{128}$$

### [단계 2] 시맨틱 학술 속성 추출
질의 $Q$를 LLM에 전달하여 정형화된 JSON 객체를 반환받습니다. 반환 스키마는 다음과 같이 제한됩니다.
```json
{
  "domain": "string or null",
  "task": "string or null",
  "method": "string or null"
}
```

### [단계 3] 퍼지 매칭 알고리즘을 이용한 어휘 매핑 및 ID 추출
추출된 문자열 속성($s_{\text{domain}}$, $s_{\text{task}}$, $s_{\text{method}}$)은 `get_fuzzy_metadata_id` 함수를 통과하며 로컬 단어장(`knowledge_meta.json`)과 비교 분석됩니다.
1. **완전 일치 검사**: 소문자로 변환된 속성 문자열이 단어장에 키값으로 직접 존재하면 매칭된 고유 정수 ID($ID \ge 1$)를 즉시 반환합니다.
2. **부분 일치 검사**: 단어장의 키가 속성 문자열을 포함하거나 그 반대의 경우 매핑합니다.
3. **토큰 단위 분할 검사**: 속성 문자열을 공백으로 분할하여 길이가 3글자를 초과하는 개별 단어가 단어장 키의 일부로 존재하는지 확인하여 일치할 경우 매핑합니다.
4. **대체 기각**: 모든 조건에 미부합 시 결측 및 패딩 기호에 해당하는 **`0`**을 할당합니다.

### [단계 4] 가상 쿼리 임베딩 동적 조합
획득한 $ID_{\text{domain}}$, $ID_{\text{task}}$, $ID_{\text{method}}$를 학습 완료된 GNN 모델의 Embedding 파라미터 테이블에 입력하여 학습된 지식 공간 상의 물리 벡터를 룩업합니다. 
* $\vec{v}_{\text{domain}} = \text{Embedding}(ID_{\text{domain}}) \in \mathbb{R}^{128}$
* $\vec{v}_{\text{task}} = \text{Embedding}(ID_{\text{task}}) \in \mathbb{R}^{128}$
* $\vec{v}_{\text{method}} = \text{Embedding}(ID_{\text{method}}) \in \mathbb{R}^{128}$

최종 가상 쿼리 노드 임베딩 $\vec{q}$는 원본 텍스트 벡터에 모델 매개변수 가중치 $\alpha$(`KNOWLEDGE_WEIGHT = 0.1`)를 곱하여 선형 결합을 수행합니다.
$$\vec{q} = \vec{e}_{\text{text}} + \alpha \cdot (\vec{v}_{\text{domain}} + \vec{v}_{\text{task}} + \vec{v}_{\text{method}})$$

### [단계 5] GNN 추론 및 코사인 유사도 랭킹 산출
1. 전체 노드 간 연결을 담은 통합 인접 관계 그래프 $G_{\text{unified}}$를 구축합니다.
2. `ArxivLightGCNV4` 모델에 $G_{\text{unified}}$를 통과시켜 모든 논문 노드의 다단계 이웃 전파가 누적 반영된 최종 노드 표현 행렬 $\mathbf{E}_{\text{paper}}$를 계산합니다.
$$\mathbf{E}_{\text{paper}} \in \mathbb{R}^{N \times 128} \quad (N \approx 16,000)$$
3. 조합된 가상 쿼리 노드 벡터 $\vec{q}$와 전체 논문 표상 행렬 $\mathbf{E}_{\text{paper}}$ 간의 코사인 유사도를 계산합니다.
$$\text{Sim}(i) = \frac{\vec{q} \cdot \vec{e}_{\text{paper}, i}}{\|\vec{q}\| \|\vec{e}_{\text{paper}, i}\|} \quad (1 \le i \le N)$$
4. 유사도 값이 가장 높은 상위 $K$개의 논문 인덱스를 추출하여 제목 및 기존 지식 태그 정보와 함께 사용자에게 노출합니다.

---

## 5. v2 아키텍처의 구조적 제한 사항

`run_nl_inference_v2.py`가 채택한 하이브리드 아키텍처는 다음과 같은 기술적 임계점을 내포하고 있습니다.

### 4.1. 규칙 기반 어휘 매핑의 취약성
자연어를 ID 공간으로 정렬하기 위해 사용된 `get_fuzzy_metadata_id` 함수는 단순 문자열 매칭에 크게 의존합니다. 사용자의 자연어 입력이 학습 사전에 등록된 표현과 의미상 동의어 관계일지라도 단순 철자가 다른 경우 매칭에 실패하여 `0`번(Unknown) 벡터로 전락하는 구조적 한계가 존재합니다.

### 4.2. 정보의 비연속적 차단
단어 검색에서 매핑 기각이 누적될 경우, 쿼리 결합 공식 $\vec{q} = \vec{e}_{\text{text}} + \alpha \cdot (0 + 0 + 0)$에 의해 GNN 지식 모델의 파라미터가 배제되고 오직 OpenAI 범용 임베딩으로만 검색하게 되어 그래프 인접 신호 기반의 추천 파워가 대폭 상실되는 병목 지점이 존재합니다. 

*(주: 이 제한 사항들은 v3 엔진으로 이행되면서 모든 어휘 사전을 OpenAI 벡터 유사도 공간 상에서 즉석 탐색하는 '제로샷 시맨틱 벡터 정렬'로 보완 및 해결되었습니다.)*
