# LightGCN 지식 임베딩 연동 이상 현상 및 V4 아키텍처 개선 보고서

본 보고서는 Arxiv 학문 분야 정보를 결합한 지식 하이브리드 추천 모델의 이전 구조에서 발견된 치명적인 신경망 단절 현상을 진단하고, 이를 수학적·코드 아키텍처 수준에서 수정한 V4 모델의 아키텍처 명세 및 성능 향상 성과를 기술합니다.

---

## 1. 이전 모델의 아키텍처 결함 진단

기존 추천 모델 코드인 `LGCmodel_v2.py` 및 이를 사용하는 추론 모델들에는 논문의 메타 지식 정보를 임베딩 벡터로 변환하기 위해 다음과 같은 `nn.Embedding` 레이어들이 신경망 초기화 단계에 정의되어 있었습니다.

```python
self.domain_emb = nn.Embedding(meta_counts['domains'] + 1, embedding_dim, padding_idx=0)
self.task_emb = nn.Embedding(meta_counts['tasks'] + 1, embedding_dim, padding_idx=0)
self.method_emb = nn.Embedding(meta_counts['methods'] + 1, embedding_dim, padding_idx=0)
```

그러나 실제 오차 역전파 과정에서 이 임베딩 가중치들이 업데이트되지 않는 심각한 결함이 식별되었으며, 그 원인은 다음과 같이 분석되었습니다.

### 1.1. 순전파 연산 그래프에서의 지식 임베딩 누락
*   **원인**: `forward()` 함수 연산 파이프라인에서 입력받은 지식 임베딩 레이어들이 논문의 기초 텍스트 피처(`paper_x`)에 수학적으로 결합되지 않고 완전히 누락되어 있었습니다.
*   **결과**: BPR Loss가 계산되고 PyTorch 자동 미분 엔진(Autograd)이 편미분을 수행할 때, 지식 임베딩 레이어 파라미터까지 미분 계산 값이 도달하지 못하는 **"연산 그래프 단절 현상"**이 발생했습니다. 
*   **실질적 손실**: 모델 메모리상에는 가중치 테이블이 할당되어 있었으나, 학습이 진행되어도 가중치가 단 한 번도 업데이트되지 않은 채 초기 난수 상태 그대로 방치되었습니다. 이는 시스템 내부적으로 메타 지식을 전혀 반영하지 못하는 껍데기 아키텍처였음을 의미합니다.

### 1.2. 저자 및 주제 노드의 그래디언트 소실
*   저자와 주제 노드의 피처 표현은 학습 전에 단순히 이웃한 논문들의 임베딩 평균값을 취하는 정적 행렬 계산으로 한번 생성된 후, 연산 그래프 내에서 상수로 취급되었습니다. 이로 인해 모델 학습 시 오차율을 줄이기 위해 최적의 벡터 공간으로 진화해야 할 저자 및 토픽 표상이 전혀 학습되지 않고 정적으로 박제되는 한계가 있었습니다.

## 2. 해결 방안: V4 아키텍처의 해결 매커니즘

식별된 연산 그래프 단절 및 정적 임베딩 한계를 종식하기 위해 모델을 `ArxivLightGCNV4` 아키텍처로 개편하였습니다.

### 2.1. 동적 지식 결합의 복원
GNN의 메시지 패싱 루프를 시작하기 전, 각 논문 노드에 할당된 Domain, Task, Method ID를 참조하여 동적으로 지식을 피처 공간에 주입하는 `_get_combined_embedding` 메서드를 연산 그래프 내부에 명시적으로 삽입하였습니다.

```python
def _get_combined_embedding(self):
    # 1. 지식 Embedding 레이어를 순전파 그래프에 포함 (Gradient 추적 개시)
    d_val = self.domain_emb(self.paper_knowledge_ids[:, 0])
    t_val = self.task_emb(self.paper_knowledge_ids[:, 1])
    m_val = self.method_emb(self.paper_knowledge_ids[:, 2])
    
    # 2. 텍스트 임베딩(paper_base_x)에 조율 가중치(knowledge_weight = 0.1)를 반영하여 선형 합성
    dynamic_paper_x = self.paper_base_x + self.knowledge_weight * (d_val + t_val + m_val)
    
    # 3. 그래프 합성 전파를 위해 다른 메타 노드들과 합산 결합하여 반환
    return torch.cat([dynamic_paper_x, self.author_emb, self.topic_emb], dim=0)
```

이 연산 구조를 복원함으로써 BPR Loss로부터 시작된 미분 기울기가 `dynamic_paper_x`를 타고 거꾸로 흘러 들어가 **`domain_emb`와 `task_emb`, `method_emb` 가중치들이 정상적으로 경사 하강법에 의해 학습되도록 유도**하였습니다.

### 2.2. 저자 및 주제 노드의 매개변수화
정적으로 고정되어 있던 저자 및 주제 노드 표현 벡터를 `nn.Parameter`로 감싸 역전파 그래프에 완벽하게 등재하였습니다.
```python
self.author_emb = nn.Parameter(author_x)
self.topic_emb = nn.Parameter(topic_x)
```
초기화 시점에는 기존처럼 논문의 평균 특징값을 수혈받아 콜드 스타트 강인성을 유지하되, 전체 학습 에포크가 진행됨에 따라 **협업 필터링 관점에서 인용 패턴에 따라 저자와 주제 고유 벡터가 더욱 최적의 표현으로 자가 업데이트**되도록 유도하였습니다.

## 3. 개선 효과 및 성능 향상 분석

연산 단절을 완전히 제거한 V4 아키텍처 기반 Ours 모델의 성능 변화는 엄격하게 데이터 누수가 차단된 신규 벤치마크 v2 프레임워크 상에서 다음과 같이 입증되었습니다.

### 3.1. 일반 추천 성능 (Recall@20)
*   **개선 전 비학습 모델 계열**: 일반 GCN + BPR (28.27%), GraphSAGE + BPR (27.31%)
*   **개선 후 V4 지식 주입 모델 (Ours)**: **38.78% (베이스라인 대비 최대 10.51%p 향상)**
*   **평가**: 지식 공간의 가중치가 유기적으로 학습되면서 인용 그래프의 협업 신호와 메타데이터의 시맨틱 정렬 성능이 극대화되어, 학계에서 최상위권으로 꼽히는 경량 LightGCN 단독 모델(37.50%)조차 뛰어넘는 강력한 성능을 확보하였습니다.

### 3.2. 신규 논문 추천 성능 (NDCG@20)
*   **일반 GCN 베이스라인**: 0.0024
*   **V4 지식 주입 모델 (Ours)**: **0.0953 (약 40배에 달하는 성능 폭등)**
*   **평가**: 그래프에 인용 링크가 없는 새로운 논문이 진입했을 때, GNN의 메시지 패싱이 가로막힌 절망적인 상황에서도 **그동안 정교하게 학습 완료된 V4 학술 속성 임베딩들이 원본 텍스트에 긴밀히 수혈**되어 신규 노드의 임베딩 강건성을 견고하게 끌어올렸음을 증명합니다.
