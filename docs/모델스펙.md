# Arxiv 논문 추천 시스템 모델 명세서

이 문서는 Arxiv 논문 추천 시스템에 구현된 각 모델의 아키텍처, 학습 방법 및 주요 특성을 상세히 설명합니다.

---

## 1. 개요
본 프로젝트는 논문 간의 인용 관계와 저자, 주제 등의 메타데이터를 활용하여 사용자에게 최적의 논문을 추천하는 시스템을 구축합니다. 특히, 인용 관계가 없는 신규 논문에 대한 추천 성능을 극대화하기 위해 LLM 기반의 지식 추출 기법을 도입했습니다.

---

## 2. 모델별 상세 설명

### Tier 1: 비그래프 베이스라인

#### **BPR-MF**
*   **특징:** 가장 고전적이고 강력한 추천 알고리즘입니다. 그래프 구조를 명시적으로 고려하지 않고 논문 간의 직접적인 연결 패턴만 학습합니다.
*   **데이터:** 논문의 ID 간 연결 여부만 사용합니다.
*   **학습 방식:** 논문 임베딩 간의 내적을 통해 유사도를 계산하며, BPR Loss를 통해 상대적 순위를 최적화합니다.
*   **장단점:** 학습이 빠르고 데이터가 많을 때 안정적이지만, 새로운 논문에 대한 추천이 불가능합니다.

---

### Tier 2: 그래프 신경망 베이스라인

#### **GCN + BPR / GraphSAGE + BPR**
*   **특징:** 논문의 주변 이웃 정보를 집계하여 논문의 특징을 추출합니다.
*   **데이터:** 인용 네트워크의 인접 행렬과 초기 텍스트 피처를 사용합니다.
*   **학습 방식:** 메시지 패싱을 통해 다단계 이웃 정보를 반영합니다.
*   **차이점:** GCN은 고정된 가중치를 사용하고, GraphSAGE는 이웃 샘플링 및 다양한 집계 함수를 사용합니다.

#### **LightGCN**
*   **특징:** 추천 시스템에 최적화된 경량화된 GNN 모델입니다.
*   **데이터:** 인용 네트워크 구조만 집중적으로 학습합니다.
*   **핵심 로직:** 기존 GCN에서 복잡한 비선형 활성화 함수와 가중치 행렬을 제거하고, 오직 선형적인 전파를 통해 협업 필터링 신호를 강화합니다. 현재 학계에서 가장 성능이 우수한 구조 중 하나입니다.

---

### Tier 3: 제안 모델

#### **LightGCN + Knowledge**
*   **특징:** LightGCN 구조 위에 LLM이 분석한 학술적 지식을 결합한 하이브리드 모델입니다.
*   **추가 데이터:** DeepSeek 등의 LLM을 통해 추출한 분야, 태스크, 사용 기법 메타데이터.
*   **핵심 메커니즘:**
    1.  **지식 주입:** 각 논문이 가진 지식 속성을 임베딩화하여 논문의 기본 벡터에 결합합니다.
    2.  **가중 통합:** 지식 정보가 기존 구조 정보를 방해하지 않도록 `knowledge_weight`(기본값 0.1)를 적용하여 조절합니다.
*   **강점:** 인용이 없는 신규 논문이라도 "어떤 기법을 썼는지", "어떤 태스크를 다루는지"를 기반으로 정확하게 추천할 수 있습니다.

---

## 3. 공통 학습 및 평가 프로세스

### 학습 방식: BPR
모든 모델은 쌍별 학습 방식을 따릅니다.
*   실제 인용된 논문의 점수는 높이고, 인용되지 않은 논문의 점수는 낮추도록 학습하여 최적의 추천 순위를 찾아냅니다.

### 주요 평가 지표
1.  **NDCG:** 정답 논문이 추천 리스트 상단에 있을수록 높은 점수를 부여하는 순위 품질 지표입니다.
2.  **재현율:** 상위 K개의 리스트 안에 실제 정답 논문이 얼마나 포함되어 있는지를 측정합니다.
3.  **CS-Metrics:** 신규 논문 시뮬레이션 환경에서의 성능을 별도로 측정하여 모델의 실용성을 검증합니다.

---

## 4. 모델 성능 최적화 노트
*   **가중치 조절:** 지식 임베딩의 반영 비중이 너무 크면 기존 인용 정보가 노이즈로 덮일 수 있으므로, `knowledge_weight`를 통해 인용 구조(90%)와 지식 정보(10%)의 균형을 맞춥니다.
*   **통합 그래프:** Paper-Author-Topic 관계를 하나의 큰 통합 그래프로 구축하여 보다 풍부한 문맥을 학습합니다.
