SVG 섹션 내보내기

01-recommended-papers.svg : 추천 논문 TOP 3 및 점수 상세
02-recommended-authors.svg : 추천 연구자 및 점수 구성
03-conversation.svg : 화면 제목, 사용자 질문, AI 응답, 입력창과 보내기 버튼

PowerPoint: 삽입 > 그림 > 이 장치에서 SVG 파일을 선택하세요.
글자와 도형으로 구성된 SVG이며 비트맵 이미지 및 foreignObject는 사용하지 않았습니다.
한글 글꼴은 맑은 고딕(Malgun Gothic)을 사용합니다.
점수와 추천 데이터는 발표용 예시입니다.
index.html은 세 파일을 한 번에 확인하는 미리보기입니다.
layout.json은 브라우저에서 추출한 좌표와 스타일 정보입니다.

세 개별 SVG의 실제 삽입 너비는 모두 280mm(28cm)로 통일했습니다. 04-aligned-sections.svg는 세 섹션을 같은 좌우 기준으로 세로 정렬한 통합본입니다.
