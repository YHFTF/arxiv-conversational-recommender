# Arxiv 지식 그래프 기반 자연어 추천 엔진 최종 결과 보고서

본 보고서는 개편된 GNN 네이티브 내적(Dot Product) 기반 자연어 추천 추론 엔진의 큐레이션 품질을 평가하기 위해 세 가지 대표 학술 질의를 대상으로 수행한 배치 테스트 결과를 기술하며, 시스템의 한계점과 향후 개선 방향을 객관적으로 분석합니다.

---

## 1. 테스트 개요

본 평가는 사용자의 자연어 질의를 입력받아 NLU 파서, 제로샷 시맨틱 소프트 매핑, GNN 내부 지식 쿼리 합성을 거쳐 도출된 상위 5개의 최종 추천 논문의 정성적 품질을 측정합니다. 이를 통해 모델의 인양 정확도를 확인하고, 실제 추천 스코어링 과정에서 발생하는 구조적 한계를 도출합니다.

## 3. 현 아키텍처의 구조적 문제점 및 단점

배치 테스트 분석 결과, 시스템은 다음과 같은 세 가지 근본적인 기술적 임계점을 나타냈습니다.

### 3.1. 내적(Dot Product) 계산에 따른 노드 차수 편향 (Degree / Popularity Bias)
* **원인**: GNN BPR Loss는 그래프 연결성이 강하고 인용이 누적된 중요 노드일수록 벡터의 크기(Norm) 자체를 크게 팽창시키도록 가중치를 학습합니다.
* **문제점**: 이로 인해 내적 계산 시, 질문의 세부 키워드와 완벽히 부합하지 않더라도 인용 구조상 강력한 지배력을 가진 거대 허브 논문(예: 질의 2의 로봇 손 논문)이 상위권을 독점하여 정밀한 타겟팅을 방해하는 **인용 빈도 편향**이 발생합니다.

### 3.2. NLU 번역 및 매핑 단계의 종속성 (Parsing Cascading Error)
* **원인**: 추론 엔진은 사용자의 자유 자연어를 먼저 3개의 속성 명사로 규격화한 뒤 GNN ID로 변환합니다.
* **문제점**: 자연어 파서(`gpt-4o-mini`)나 단어장 소프트 매퍼가 첫 단계에서 속성 매핑을 미세하게 오판할 경우(예: `legged`를 단순히 넓은 의미의 `soft hand` 제어 가중치에 동조시킴), GNN 공간 내 쿼리는 처음부터 오염된 좌표에서 시작하게 되며 이 하향식 오류(Cascading Error)가 랭킹 품질 전체를 붕괴시킵니다.

### 3.3. 닫힌 단어장 제약 (Closed Vocabulary Constraint)
* **원인**: 로컬 지식 그래프와 어휘 사전(`knowledge_meta.json`)은 학습 당시 구축된 고정된 엔티티 사전에 갇혀 있습니다.
* **문제점**: 사용자가 사전에 정의되지 않은 최첨단 개념(예: `Neuromorphic locomotion`)을 질의할 경우, 소프트 매칭을 통과해도 사전 내의 가장 덜 어색한 부적합 단어로 우회 매핑될 수밖에 없어 고질적인 폐쇄성 문제를 극복하기 어렵습니다.

## 4. 향후 기술 개선 방향

1. **하이브리드 정규화 점수 도입 (Degree Bias 완화)**:
   * 단순 내적 스코어와 L2 정규화가 가미된 코사인 유사도 사이의 조율(예: 온도 매개변수 $\tau$를 가미한 스코어 스케일링)을 도입하여, 유명 논문에 밀려 누락되는 '미시적 주제 부합 명작 논문(Tail papers)'의 인양력을 회복해야 합니다.
2. **동적 가상 노드 주입 기술 연구 (Dynamic Node-Injection)**:
   * 사전에 없는 개념 입력 시, 기계적 매핑에 그치지 않고 Word2Vec 유사도 분포를 기반으로 GNN 그래프 구조에 가상 노드(Virtual Node)를 즉각 동적 생성하여 훈련 과정 없이 GNN 전파 신호를 모사하는 추론 기술을 탑재해야 합니다.
3. **다단계 속성 검증 체인 구축**:
   * NLU 파싱 단계의 정합성을 보장하기 위해, 추출된 학술 키워드가 데이터셋 단어 사전과 모순이 없는지 스스로 교차 검증하고 재수정하는 자체 성찰(Self-Reflection) 프롬프트 루프를 추가해야 합니다.
