# GNN 기반 자연어 추천의 인기 편향(Popularity Bias) 고찰 및 해결 방안 보고서

본 보고서는 Arxiv 지식 그래프 기반 자연어 추천 시스템의 v2 추론 엔진 평가 과정에서 발견된 내적(Dot Product) 연산의 인기 편향(Popularity/Degree Bias) 현상을 규명하고, 이에 대한 학술적 고찰 및 단계별(학습단/추론단) 해결 방안을 기술합니다.

---

## 1. 개요 및 문제 제기

GNN 네이티브 내적 기반 추론 엔진(`run_nl_inference_v2.py`)은 90% 지분의 Word2Vec 텍스트 표상과 10% 지분의 GNN 지식 임베딩을 성공적으로 결합하여 높은 의미적 정렬을 보여주었습니다.

그러나 정밀 검증 과정에서 구체적인 니치 도메인 질의(예: Cassie 이족 보행 로봇 제어)에 대해, 의미적으로 완벽하게 일치하는 전문 논문들이 데이터셋 내에 풍부하게 존재함에도 불구하고, 인용수가 압도적으로 많은 광범위한 유명 논문(예: OpenAI의 로봇 손 제어 연구)이 상위 추천을 독점하는 현상이 관찰되었습니다.

본 보고서는 이러한 왜곡 현상이 단순한 데이터 부재가 아닌, GNN 그래프 구조와 BPR(Bayesian Personalized Ranking) 학습 알고리즘의 결합에서 발생하는 구조적 한계임을 수학적으로 규명합니다.

---

## 2. 팩트 체킹을 통한 현상 분석

실제 16,000편의 Arxiv 논문 서브데이터셋을 전수 조사하여 매칭 정밀도를 분석한 결과는 다음과 같습니다.

### 2.1. 데이터셋 내 타겟 논문의 존재 여부 (Fact Check)

분석 결과, 데이터베이스 내에는 사용자가 질의한 '이족 보행 로봇 제어(Bipedal Locomotion, Cassie)'와 관련하여 100% 주제에 부합하는 타겟 연구가 **총 26편 명확하게 존재**하고 있었습니다.

- `feedback control of a cassie bipedal robot walking standing and riding a segway`
- `iterative reinforcement learning based design of dynamic locomotion skills for cassie`
- `rapid bipedal gait design using c frost with illustration on a cassie series robot`

### 2.2. 추천 결과 왜곡 현상 (Popularity Bias)

질의어에 대해 실제 직격 논문인 Cassie 관련 연구들은 매칭 점수 **17 ~ 22점 대**에 머무르며 상위 5위권 밖으로 밀려났습니다. 반면, 다리 보행이 아닌 손 제어 논문인 `learning dexterous manipulation for a soft robotic hand`가 **36.94점**으로 압도적인 1위를 차지했습니다.

이는 모델이 자연어의 구체적인 세부 맥락보다, 특정 노드의 **학술적 인용 권위(Prestige)**에 비정상적으로 강하게 지배당하고 있음을 증명합니다.

## 3. 구조적/학술적 고찰

### 3.1. GNN BPR 학습 알고리즘에 따른 벡터 Norm 팽창

BPR Loss 학습 시 GNN 모델은 긍정 노드(인용된 연결 관계)에 대해 내적 스코어를 극대화하도록 학습을 진행합니다.

- **인기 노드(Hub Node)**: 인용망 상에서 수많은 연결(Edge)을 가진 논문 노드는 역전파 과정에서 무수히 많은 그라디언트(Gradient) 신호를 수집하게 됩니다.
- **벡터의 기하학적 팽창**: 이로 인해 인기 노드는 다른 평범한 노드들에 비해 임베딩 공간 상에서 벡터의 L2 크기(Norm, $\|\vec{e}_{v}\|$) 자체를 거대하게 팽창(일반 노드 대비 최대 10배 이상)시키는 방식으로 학습을 완료합니다.
- **내적(Dot Product)의 취약점**: 추론 시 코사인 유사도와 달리 내적 스코어는 벡터의 크기가 클수록 결과값이 비례하여 팽창합니다. 결국 주제의 일치율(방향 차이)이 다소 떨어지더라도 체급이 거대한 인기 노드가 최종 랭킹 점수를 독식하게 되는 수학적 원인이 발생합니다.

### 3.2. 오프라인 NDCG 지표의 착시 현상 (Trade-off)

인기 편향을 억제하는 탈편향(Debiasing) 조치를 취할 경우, 오프라인 벤치마크 검증 상에서 수치적인 NDCG 성적은 소폭 하락하는 현상이 발생할 수 있습니다.

- **원인**: 오프라인 평가를 위한 테스트 데이터셋 자체가 이미 인용이 편향된 데이터(과거 학자들의 롱테일 인용 분포)로 구성되어 있기 때문입니다. 즉, 뻔한 대작 논문을 많이 추천할수록 오프라인 정답지와 겹쳐 점수가 올라가는 평가지표 고유의 한계(Popularity Bias Shortcut)가 존재합니다.
- **해석**: 오프라인 NDCG의 미세한 하락은 추천 품질의 붕괴가 아니라 데이터셋에 존재하던 구조적 거품(인기 편향)이 걷히고 **진짜 시맨틱 매핑력**이 복원되는 과정입니다.

## 4. 단계별 기술적 해결 방안

우리는 인용수가 높은 대작 논문이 가진 학술적 신뢰도(Prestige)도 인정하면서, 니치한 논문들의 세부 정확성도 잃지 않는 황금 밸런스를 달성하기 위해 다음과 같은 단계별 아키텍처를 도입할 수 있습니다.

### 4.1. [단기 / 추론단 해결책] 명시적 인용 오프셋 분리 및 가중치 제어 (Decoupled Popularity Offset)

GNN 임베딩 자체에서 인용도의 지배력을 강제로 격리시키고, 이를 추론 엔진 단에서 정밀하게 사후 제어하는 방식입니다.

- **수학적 설계**:
  임베딩 간의 유사도는 L2 크기가 완전히 통제된 코사인 유사도로 100% 순수한 주제 방향 일치성만 평가하고, 뒤에 로그 스케일로 정규화된 인용 가산점을 명시적으로 결합합니다.
  $$\text{Score}(i) = \cos(\vec{q}, \vec{e}_{\text{paper}, i}) + w_{\text{prestige}} \times \log(\text{CitationCount}_{i} + 1)$$
  - $w_{\text{prestige}}$: 학술적 권위 가중치 (추천 엔진의 사후 튜닝 매개변수)
- **장점**: 모델 재학습 비용이 전혀 발생하지 않으며, 서비스 성향(안전한 명저 위주 추천 vs 신생 니치 연구 발굴)에 따라 가중치를 실시간 다이얼처럼 유연하게 조율하여 오프라인 NDCG 낙폭을 완전히 방어할 수 있습니다.

### 4.2. [장기 / 학습단 해결책] 차수 기반 L2 임베딩 정규화 페널티 차등 적용 (Degree-dependent L2 Regularization)

GNN 모델이 학습하는 단계에서 인기 노드의 벡터 크기가 무분별하게 팽창하지 않도록 근본적으로 제약하는 기법입니다.

- **수학적 설계**:
  학습 루프 내부에서 인용 차수(Degree)가 큰 논문 노드일수록 가중치 감쇠(Weight Decay) 패널티를 더 강하게 적용합니다.
  $$\mathcal{L}_{\text{L2}} = \sum_{v} \lambda_{v} \|\vec{e}_{v}\|^2_2 \quad \left( \lambda_{v} = \lambda_{\text{base}} \times [\text{Degree}(v)]^\gamma \right)$$
  - $\gamma$: 편향 억제 강도 하이퍼파라미터
- **장점**: 모델이 학습 시 인용 빈도에 의한 스케일 불균형을 스스로 인지하고, 체급 차이를 일정 부분(완만하게 조율할 경우 로그 스케일 수준으로) 조율하여 임베딩 공간 자체를 물리적으로 대단히 건전하게 형성합니다.

## 5. 기대 효과 및 결언

본 보고서가 제기한 고찰과 개선안은 GNN 자연어 추천 시스템의 완성도를 한 단계 끌어올리는 중요한 도약점입니다.

1. **상용화 수준의 추천 튜닝성 확보**: 인용 오프셋 분리 제어를 통해 모델의 고정된 수식을 탈피하고 비즈니스 요구사항에 대응할 수 있는 가중치 다이얼을 획득합니다.
2. **학술 정보 신뢰성 방어**: 인기 편향을 무조건 지우는 무리한 탈편향 대신, 인용수가 많은 논문의 신뢰 가치를 적절히 가산점으로 인정해 줌으로써 학술 검색 포털 규격에 맞는 수준 높은 큐레이션을 실현합니다.
