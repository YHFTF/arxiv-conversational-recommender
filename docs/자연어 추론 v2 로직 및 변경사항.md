# 자연어 추천 추론 엔진(v2) 작동 로직 및 프로세스 명세서

본 문서는 Arxiv 지식 그래프 기반 논문 추천 시스템의 자연어 인터페이스 모델인 `run_nl_inference_v2.py`의 개편된 아키텍처 구성, 작동 매커니즘 및 상세 프로세스를 보고서 형식으로 기술합니다.

---

## 1. 개요

`run_nl_inference_v2.py`는 사용자의 자연어 질의를 분석하여 그래프 신경망 및 지식 임베딩 공간에서 최적의 논문을 검색 및 추천하는 End-to-End 추론 엔진입니다. 

본 엔진은 거대 언어 모델의 NLU 자연어 번역 능력과 LightGCN 기반 그래프 임베딩의 기하학적 내적(Dot Product) 스코어링 방식을 결합한 하이브리드 추천 방식을 채택하고 있습니다. 사용자의 추상적인 검색 의도를 구체적인 학술 카테고리 속성(Domain, Task, Method)과 정렬함으로써, 인용 관계망의 지식 구조와 Word2Vec 고유 피처 공간을 완전히 동조시킨 고밀도 추천을 보장합니다.

---

## 2. 핵심 아키텍처 및 기술 스택

본 엔진은 다음과 같은 핵심 모듈과 알고리즘으로 구성되어 있습니다.

### 2.1. NLU 기반 학술 속성 파싱
질의 텍스트에 포함된 미시적 학술 요구사항을 규명하기 위해 `gpt-4o-mini` 모델을 사용하여 개체명 인식 및 속성 분류를 수행합니다. 질의문으로부터 **Domain**, **Task**, **Method**를 사전 정의된 JSON 스키마로 추출합니다.

### 2.2. 제로샷 시맨틱 벡터 매핑 (Soft Mapping)
파싱된 자연어 학술 용어가 로컬 사전 사전에 정확히 부합하지 않을 경우 발생하는 기각 병목(ID 0번 할당)을 해결하기 위해, OpenAI의 128차원 임베딩을 이용한 벡터 매칭을 수행합니다. 추출된 속성 용어와 사전에 등록된 모든 카테고리 임베딩 간의 유사도를 연산하여, 가장 의미적으로 가까운 고유 노드 ID를 항상 매핑해 주는 유연한 Soft-Matching 체계를 탑재하였습니다.

### 2.3. 순수 GNN-Native 쿼리 합성
최종 랭킹 연산 시 물과 기름처럼 섞이지 않던 외부 OpenAI 텍스트 벡터를 완전히 차단하였습니다. 번역이 끝난 GNN 고유 지식 임베딩 가중치(`d_vec + t_vec + m_vec`)들의 선형 결합만으로 순수한 쿼리를 빌드하여, GNN이 학습한 고차원 공간 상의 표상 왜곡을 방지합니다.

### 2.4. BPR 정렬 기반 내적(Dot Product) 추론
기존 코사인 유사도 연산이 벡터의 L2 크기(Norm)를 강제로 깎아내려 GNN이 학습한 중요 논문 가중치 신호를 파괴하던 문제를 해결했습니다. 모델이 학습한 방식 그대로 **내적(Dot Product)**을 평가 척도로 채택하여, GNN의 인용 영향력 가중치와 90% 지분의 Word2Vec 특징이 극대화되어 추천에 반영되도록 수학적 구조를 전격 동조시켰습니다.

## 3. 상세 처리 프로세스

엔진이 구동되어 자연어 질의로부터 최종 추천 결과를 도출하는 과정은 총 4단계의 파이프라인으로 세분화됩니다.

```
[자연어 질의 입력]
       │
       ├──> [단계 1] gpt-4o-mini 기반 학술 속성 추출 (Domain, Task, Method)
       │
       ├──> [단계 2] OpenAI 임베딩 공간 기반 제로샷 시맨틱 소프트 매핑 (ID 변환)
       │
       ├──> [단계 3] GNN 내장 지식 임베딩 룩업 및 순수 쿼리 벡터 합성
       │
       └──> [단계 4] get_cold_start_embeddings 로드 및 내적(Dot Product) 기반 Top-K 추천
```

### [단계 1] 시맨틱 학술 속성 추출
질의 $Q$를 LLM에 전달하여 정형화된 JSON 객체를 반환받습니다. 반환 스키마는 다음과 같이 제한됩니다.
```json
{
  "domain": "string or null",
  "task": "string or null",
  "method": "string or null"
}
```

### [단계 2] 제로샷 시맨틱 소프트 매핑
추출된 문자열 속성($s_{\text{domain}}$, $s_{\text{task}}$, $s_{\text{method}}$)은 `find_best_semantic_match` 함수를 통과하며 고유 ID로 번역됩니다.
1. **완전 일치 검색**: 대소문자를 무시하고 단어장에 키값으로 직접 존재하면 매칭된 고유 정수 ID를 즉시 반환합니다.
2. **시맨틱 임베딩 매칭**: 단어장에 매칭되는 단어가 없을 때, 입력 용어의 128차원 OpenAI 임베딩과 사전 빌드된 어휘 사전 임베딩 행렬 간의 코사인 유사도를 계산하여 **가장 의미상 유사한 단어**의 정수 ID를 최종 선정하여 기각을 전면 방지합니다.

### [단계 3] GNN 쿼리 임베딩 동적 조합
획득한 $ID_{\text{domain}}$, $ID_{\text{task}}$, $ID_{\text{method}}$를 학습 완료된 GNN 모델의 Embedding 파라미터 테이블에 입력하여 학습된 지식 공간 상의 물리 벡터를 룩업합니다. 
* $\vec{d}_{\text{vec}} = \text{domain\_emb}(ID_{\text{domain}}) \in \mathbb{R}^{128}$
* $\vec{t}_{\text{vec}} = \text{task\_emb}(ID_{\text{task}}) \in \mathbb{R}^{128}$
* $\vec{m}_{\text{vec}} = \text{method\_emb}(ID_{\text{method}}) \in \mathbb{R}^{128}$

최종 가상 쿼리 노드 임베딩 $\vec{q}$는 지식 임베딩들의 순수 선형 결합을 통해 빌드됩니다.
$$\vec{q} = \vec{d}_{\text{vec}} + \vec{t}_{\text{vec}} + \vec{m}_{\text{vec}}$$

### [단계 4] 내적 기반 정밀 추천 및 정렬
1. 16,000편의 논문에 대해 Word2Vec 피처와 카테고리 지식 정보가 9:1의 비율로 조밀하게 합성된 원본 표상 행렬 $\mathbf{E}_{\text{paper}}$를 로드합니다.
$$\mathbf{E}_{\text{paper}} = \text{model.get\_cold\_start\_embeddings}(\text{arange}(N)) \in \mathbb{R}^{N \times 128}$$
2. 결합된 GNN 쿼리 벡터 $\vec{q}$와 전체 논문 표상 행렬 $\mathbf{E}_{\text{paper}}$ 간의 수학적 내적(Dot Product) 스코어를 연산합니다.
$$\text{Score}(i) = \mathbf{E}_{\text{paper}}[i] \cdot \vec{q}^{T}$$
3. 내적 값이 가장 높은 상위 $K$개의 논문 인덱스를 추출하여 제목 및 기존 지식 태그 정보와 함께 사용자에게 출력합니다.

---

## 4. 개편 후 아키텍처의 강점

1. **공간적 뒤틀림 해결**: 최종 랭킹 계산에서 외부 임베딩(`raw_text_emb`)을 배제함으로써, GNN이 피땀 흘려 학습한 고유 차원 공간의 물리적 순수성이 100% 보존됩니다.
2. **지식 기각 차단**: Soft Matching 체계가 도입되어 사용자가 어떤 자연어로 쿼리를 작성하든, 로컬 그래프 노드에 연결된 가장 관련성이 높은 속성 노드를 안정적으로 정렬해 냅니다.
3. **GNN 학습 원칙과의 조화**: BPR Loss 훈련 수식(Dot Product)과 완벽하게 부합하는 추론 정렬이 도입되어, 인용 영향력이 높은 명저 논문의 중요도가 자연스럽게 가중 스코어로 승화되는 학술 추천 고유의 신뢰도를 실현했습니다.
