# 시간 분리·연결 0개 콜드스타트

현재 저장된 균형 표본, 출판 연도, Qwen 제목·초록/DTM/결합 임베딩과 인용만 사용한다. LLM 판정 라벨이나 외부 API는 사용하지 않는다.

```powershell
.\venv\Scripts\python.exe -m benchmarks.cold_start
.\venv\Scripts\python.exe -m benchmarks.plot_cold_start
```

학습 <=2017, 검증 2018, 테스트 >=2019로 논문 자체를 분리한다. 학습 인용의 양 끝점과 음성 후보는 학습 노드만 사용한다. 새 노드는 학습 피처 행렬에서도 제거한다. 검증/테스트 소스는 연결 0개, 자기 연결만 있는 공유 GNN 변환으로 벡터화한다. 기존 후보는 학습 그래프로 벡터화한다. 신규 논문이 학습 논문을 인용한 관계를 숨긴 정답으로 사용한다. 후보는 전체 학습 논문 12,400편이며 신규 논문은 후보나 음성 샘플에 등장하지 않는다.

같은 Qwen 2560차원으로 제목·초록/DTM/결합 GNN을 비교한다. 학습 없는 각 표현의 코사인 검색과 기존 OGBN 128차원 GNN도 함께 기록한다. 모델 구조·hidden=128·학습률=.001·200epoch·5epoch마다 검증·NDCG@20 기준 최적 epoch 선택을 고정하고 seed=42,43,44를 반복한다. 테스트 점수로 epoch나 시간 경계를 선택하지 않는다.

학습에 쓰지 않은 노드라는 의미의 콜드스타트이며, foundation model 사전학습 미노출을 보장하는 것은 아니다. 평가 과제는 새 논문으로 기존 참고문헌을 찾는 것이며 새 논문을 사용자에게 추천하는 과제는 별도이다. 참고문헌 자체는 출판 시 이미 알려질 수 있으므로 연결 전부를 숨기는 조건은 엄격한 모사이다. 실제 받은 인용 0개와 모든 인용 연결 0개는 다르다. 논문 연도는 있지만 관계 관측 시각은 없어 완벽한 역사적 그래프를 복원했다고 주장하지 않는다.
